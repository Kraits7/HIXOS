ГЛАВНАЯ ФИШКА HIXOS

Плавность и Физика Движения

Каждый элемент HIXOS анимирован с использованием физики пружины (Spring Curves) и размытия в реальном времени.

Интерактивный Тюнер Физики

Жесткость пружины (Stiffness) 0.5s
Масштабирование (Scale) 1.25x
Интенсивность размытия (Blur) 20px
Нажмите на карточку для проверки физики

АРХИТЕКТУРА И ДВИЖОК

Две Версии — Одна ДНК

HIXOS функционирует как нативное десктопное приложение и в веб-среде

PyQt5 Native Edition

Полноценный симулятор телефона, исполняемый на Python с использованием графической библиотеки PyQt5. Высокая производительность, аппаратное ускорение и поддержка локальных файловых систем.

  • Прямой доступ к системе через Python
  • Нативный Qt 5 интерфейс с кастомными стилями QSS
  • Плавная отрисовка окон приложения

Web & Mobile Edition

Веб-интерпретация симулятора HIXOS для запуска непосредственно в браузере или на мобильных устройствах без необходимости установки стороннего окружения.

  • Мгновенный запуск в любом современном браузере
  • Поддержка тач-жестов на смартфонах
  • Адаптивный рендеринг компонентов

УСТАНОВКА И ЗАПУСК

Быстрый Старт

Запустите HIXOS на своём ПК с помощью Python и PyQt5

1. Клонирование HIXOS 
git clone https://github.com/Kraits7/HIXOS.git
cd HIXOS
2. Установка зависимостей PyQt5 
pip install PyQt5
3. Запуск симулятора 
python main.py
